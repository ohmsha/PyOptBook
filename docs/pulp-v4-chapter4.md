# PuLP 4.0 移行メモ（第4章）

## 変更内容

`coupon.ipynb` の会員別の整数計画、セグメント別の連続計画、2段階の最適化と予算別の計算を移行する。変数は `problem.add_variable(...)` で生成し、求解は `pulp.COIN_CMD(gapRel=0, gapAbs=0)`、表示は `stats.status_str` を使う。既存 PR #2 のファイルをそのまま引き継ぐ。

2段階最適化では、第1段階の非負の送付率を小数点以下8桁で切り捨てて第2段階へ渡す。旧 CBC が出力した値と精度を合わせるためで、新 CBC の細かい桁をそのまま制約の下限に使うと第2段階が実行不能になることを既存の移行検証で確認した。既存の説明コメントは維持する。

## 検証と出力

5,000人の同梱データを使い、全コードセルと27回の求解を実行する。モデルの規模、変数の上下限・整数性、全制約と目的値を移行前の基準値と比較する。整数モデルの基準値は326.09で、書籍付属 Notebook の保存表示326.1と丸め後に一致する。書籍紙面との直接照合はしていない。

既存 PR で全セルを実行した出力・表・グラフ・実行番号を維持する。送付先に複数解がある場合は、個々の ID の完全一致を要求しない。整数モデルは環境により探索が長引くことがあり、元のコメントにある許容ギャップの設定も確認する。許容ギャップを設定した結果と厳密な最適性の判定を区別する。

```sh
python -m pip install -r requirements-test.txt
python -m pytest -q tests/test_chapter4.py
```
