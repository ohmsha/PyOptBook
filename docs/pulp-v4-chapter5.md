# PuLP 4.0 移行メモ（第5章・初版と第2版）

## 変更内容

`5.routing/routing.ipynb` と `5.routing_ver2/routing_ver2.ipynb` を同じ章の移行としてまとめる。既存 PR #2 のファイルをそのまま引き継ぐ。問題から変数を生成し、`COIN_CMD` と `LpSolveStats` を使う。厳密な最適解を求める箇所は `gapRel=0, gapAbs=0`、大規模モデルの `gapRel=0.1` は維持する。

初版では空の数式を `pulp.LpAffineExpression.empty()` に変更する。各ワーカー内で問題を作成し、PuLP の問題オブジェクトをプロセス間で渡さない。現在の IPython / pandas に合わせ、`IPython.display` と `.loc[sorted(index_set)]` に変更する。既存コメントと並列数は維持する。

第2版の TSP 関数は結果オブジェクトを返し、呼び出し側も `stats.status == pulp.LpSolveStatus.Optimal` で判定する。大規模モデルは、PuLP 3.x が CBC に渡していた変数名の辞書順に合わせ、`h, u, x, y` の順と `sorted(..., key=str)` で生成する。数式を変えずに探索順の変化を抑えるためである。

## 検証と出力

| ケース | 入力と検証 | 求解数 |
| --- | --- | ---: |
| 初版 | 地点4・日数5・荷物12の縮小データで列挙から選択まで | 9 |
| 第2版・小規模 | 同梱 small CSV、直接定式化と列挙方式 | 18 |
| 第2版・TSP | 元データの実行可能・実行不能の2例 | 2 |
| 第2版・大規模 | 元データ、`gapRel=0.1` | 1 |

全モデルで変数数・制約数、上下限・整数性・全制約を検証する。最適性が確認済みの例は移行前の目的値と比較する。大規模モデルの暫定目的値は一致を要求せず、CBC の下界と許容ギャップ内であることを確認する。別テストで2プロセスのルート列挙も実行する。

CI の大規模テストだけは、既存の `routing_initial_solution.csv` を初期値にし、CBC の前処理による初期解の棄却を避けるため `preprocess off` を指定する。変数を固定せず再求解し、時間切れの結果は合格にしない。各求解の上限は120秒、大規模のみ600秒とする。

Notebook の保存出力は、縮小や初期解の追加をせず、同梱データで全セルを実行した既存 PR の結果を維持する。テスト用の変更を保存出力に適用しない。別環境ではカーネルを再起動して先頭から実行する。

```sh
python -m pip install -r requirements-test.txt
python -m pytest -q tests/test_chapter5.py
```

## 書籍への修正候補

- 初版・第2版の変数定義、空の式、CBC の指定と求解結果の取得を更新する。
- TSP の戻り値とルート列挙の判定、並列処理で問題を各プロセス内に作ることを説明する。
- 許容ギャップによる終了が最適性の証明とは異なることを説明する。旧版の `Optimal` 表示に対して、新版では `GapLimit` となる場合がある。
- 複数最適解の経路や許容ギャップで終了した目的値、計算時間は CBC の版・OS・探索順により変わることを出力例に補足する。
