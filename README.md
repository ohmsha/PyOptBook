## 本書について

> **Pythonで実務に使える数理最適化のスキルを身につけよう！**
>   
> 本書は、Pythonを用いた数理最適化の入門書です。Pythonを使ってさまざまな課題を実際に解いてみることで、数理モデルを実務で使いこなす力を身につけます。  
> この本の特徴は、数理最適化のアルゴリズム自体ではなく、数理最適化を用いた課題解決に重きを置いている点です。ビジネスなどにおける課題を数理最適化で解く際に現場で発生しうる試行錯誤が多分に盛り込まれており、実務における手順や気をつけるべきポイントを学習することができます。  
>
> **この本の構成**  
> 本書は二部構成です。  
> 第I部はチュートリアルです。中学校で習う連立一次方程式や高校で習う線形計画法を題材として、数理最適化の基礎的な考え方とPythonによる初歩的な実装を学びます。シンプルな課題設定なので、数学的な難しさを感じることなくPythonに集中して基礎を学習することができます。
> 
> 第II部はケーススタディです。  
> 実際に社会で起こりうる、さまざまな課題を数理最適化によって解いていきます。
学校のクラス編成やサークル活動における学生の乗車グループ分けなどの学生にとっても身近な課題や、キャンペーンの効果最大化や効率のよい配送計画の立案などのビジネスにおいてたびたびぶつかる課題などを解いていくことで、手順や注意点、効率のよい方法などが学べます。
> 
> このような方におすすめ  
> ◎ 数理最適化の実務応用について知りたい方  
> ◎ 施策の効果最大化や効率化に取り組むビジネスマン（エンジニア・マーケター・リサーチャーなど）  
> ◎ 情報・経済・経営系などの学部や学科の学生  
> ◎ データサイエンティストを志す方


## **【重要】PuLPのバージョンについて**
2026年9月25日に Python ライブラリ PuLP が3系から4系にメジャーバージョンアップしました。PuLP 4系では本書のサンプルコードをそのまま実行できないことに注意してください。本書では `requirements.txt` にてPuLP 3.2.2 を推奨しています。

### PuLP3系のインストール方法（推奨）
書籍のサンプルコードを実行するため、PuLP 3.2.2 をインストールしてください。PuLP 3.2.2 には Python 3.9 以上が必要です。

pipを利用する場合：

```bash
pip install "pulp==3.2.2"
```

### PuLP4系を利用したい場合
PuLP 4系はPython 3.12 以上が必要です。また、PuLP 4系では **ソルバーのインストール** や **コード修正** が必要です。以下では、主な変更点を以下の①〜③に示します。
その他の変更点については、PuLP公式の[移行ガイド](https://coin-or.github.io/pulp/guides/how_to_migrate_to_v4.html)をご確認ください。

#### ①ソルバーのインストール

PuLP 4系ではCBCソルバーが標準で同梱されなくなったため、別途インストールが必要となる場合があります。

pipを利用してCBCソルバーをインストールする場合は、ターミナルで次のコマンドを実行してください。

```bash
python -m pip install pulp[cbc]
```

#### ②コード修正（変数の定義）
PuLP 3系：
```python
prob = pulp.LpProblem("problem")
x = pulp.LpVariable("x", cat="Integer")
```
PuLP 4系：
```python
prob = pulp.LpProblem("problem")
x = prob.add_variable("x", cat="Integer")
```

#### ③コード修正（最適化計算後の結果取得）

PuLP 3系：
```python
status = prob.solve()
print(pulp.LpStatus[status])
```
PuLP 4系：
```python
stats = prob.solve()
print(stats.status_str)
```
